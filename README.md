# Deep Learning for Vision and NLP
This repository contains comprehensive course materials for ITNPAI1: Deep learning for vision and NLP, taught at the University of Stirling The course covers fundamental concepts and techniques in deep learning, with a strong focus on practical aspects of deep learning.

Each week, the students will be provided with Jupyter Notebooks to practice in the lab sessions. 
The repository proivdes weekly schedule of lectures along with the practical sessions.
Practicals will be added as the course propgresses.
